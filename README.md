# zoneblob

Zone HTML/Markdown blob fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/zoneblob/

## Install / run

```bash
git clone https://github.com/theworker02/zoneblob.git
cd zoneblob
node src/cli.js
node --test
```
